One picture of food, drawn procedurally: a steaming bowl of ramen — golden
broth with chili-oil swirls, wavy noodles, ajitama eggs, chashu, green onion,
nori and chopsticks, on a warm wooden table in soft light.

## Run

```sh
python3 main.py
```

Writes a deterministic 1024x1024 PNG to `/output/entry.png` (Python 3.13,
standard library only, no network). Two runs produce byte-identical output.
